개인정보처리방침

시행일: 2026년 10월 19일

SFeed(sfeed.jyk.workers.dev)는 RSS 피드를 구독하고 읽는 서비스입니다. 이 방침은 SFeed가 어떤 정보를 수집하고 어떻게 사용하는지 설명합니다.

수집하는 정보

  • Google 로그인 시 Google이 제공하는 계정 식별자, 이메일 주소, 이름, 프로필 사진 URL
  • 서비스 이용 중 만들어지는 폴더, 구독한 피드, 읽음·북마크 상태, 화면 설정
  • 로그인 상태 유지를 위한 세션 토큰

이용 목적

수집한 정보는 로그인과 계정 식별, 구독 목록과 읽음 상태를 저장하고 여러 기기에서 동기화하는 데에만 사용합니다. 광고에 사용하거나 판매하지 않습니다.

보관 및 처리

  • 정보는 Cloudflare(Workers, D1 데이터베이스)에 저장되고 처리됩니다.
  • 세션 토큰은 로그아웃하거나 발급 후 30일이 지나면 효력을 잃습니다.
  • AI 요약이나 원문 불러오기를 사용하면 해당 기사의 공개 본문이 Cloudflare Workers AI로 전달되거나 기사 사이트에서 직접 불러와집니다. 이 과정에 계정 정보는 포함되지 않습니다.

Google 사용자 데이터

SFeed가 Google API로부터 받은 정보를 사용하는 방식은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다. Google 사용자 데이터는 위 목적 외에 사용하거나 제3자에게 제공하지 않습니다.
